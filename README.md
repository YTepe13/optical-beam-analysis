# Optical Beam Power and Attenuation Analysis

MATLAB scripts developed for electrical and electronics engineering graduation research on optical wireless communication and structured light modes.

## Contents

- `HG22.m`, `HG32.m`, `HG33real.m`, `deneme2.m`: measured optical power analysis and curve fitting.
- `Cizdirme.m`, `Cizdirme2.m`, `deneme3.m`: comparison of fitted attenuation/visibility curves for different beam profiles and wavelengths.

## Requirements

- MATLAB
- Curve Fitting Toolbox
- Original optical measurement data files (not included)

Machine-specific input paths were replaced with relative `data/` paths. Place the corresponding measurement TXT files in that folder before running the relevant scripts. Some plotting scripts rely on workspace variables created by other scripts.

This repository documents academic research code, not a packaged or independently validated software product.
